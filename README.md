# Cadastro de Pessoas Jurídicas

Aplicação web desenvolvida em Java com Spring Boot para cadastro, edição, listagem e exclusão de empresas (PJs).

## Tecnologias

- Spring Boot
- Thymeleaf
- H2 Database (memória)
- Bootstrap 5

## Como executar

```bash
git clone https://github.com/zzp4yv/cadastro-pj.git
cd cadastro-pj
./mvnw spring-boot:run
```

Acesse: [http://localhost:8080](http://localhost:8080)
